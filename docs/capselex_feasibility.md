# CAP-SELEX feasibility and shortcut diagnosis

## Purpose

The first real-data question was whether protein sequence could predict directed CAP-SELEX cooperative
pairs and their annotated mechanisms. This stage is retained as a feasibility diagnosis, not the final
biological endpoint.

## Data governance

- CAP-SELEX project: ENA `PRJEB66722`.
- 2,526 run records were audited; 2,496 were downloadable at the time of acquisition.
- Bait/prey direction is preserved. `(A, B)` is never silently equated with `(B, A)`.
- Historical symbols are normalized explicitly, including `RFXDC2 → RFX7` and `TP73L → TP63`.
- Raw reads and large matrices remain outside Git; asset hashes and run manifests are generated by code.
- A TEAD4–CLOCK smoke test reproduced all 29 published gap counts exactly from 195,679 reads, with 99.9%
  of reads passing the assay-specific parser.

## Labels

The dataset distinguishes:

1. `cooperative_signal`;
2. `composite_motif`;
3. `spacing_or_orientation`.

Mechanism labels are not merged merely to increase the positive class.

## Leakage-resistant ladder

Random read-level splitting is forbidden. The code supports:

- directed-pair holdout;
- single-TF holdout;
- structural-family-pair holdout;
- leave-one-paralogue-out challenges;
- a multi-TF panel requiring adequate positives for every target.

The baselines progress from family rates to TF identity and protein k-mers. TF identity achieved roughly
the same high AUROC as protein k-mers in the early global task, demonstrating that much of the apparent
predictability was TF-specific prevalence memory rather than transferable grammar.

## Outcome

Simple protein representations did not consistently beat family priors in HOXA2, HOXB2, or HOXB13
paralogue holdouts. A low-rank bilinear model produced isolated useful rankings but weak global AUPRC. The
pair-classification programme was therefore stopped before adding a large protein transformer.

This negative result motivated the scientifically stronger question: use CAP grammar as an independently
measured mechanistic feature and test whether it explains genomic occupancy beyond intrinsic binding.

## Reproduction

```bash
cisgrammar capselex dataset \
  --interaction-table data/capselex/interaction_matrix.xlsx \
  --construct-table data/capselex/constructs.xlsx \
  --output results/capselex/tf_pair_dataset.tsv

for target in cooperative_signal composite_motif spacing_or_orientation; do
  cisgrammar capselex tf-panel \
    --dataset results/capselex/tf_pair_dataset.tsv \
    --target "$target" \
    --output "results/capselex/tf_panel_${target}.json"
done
```
