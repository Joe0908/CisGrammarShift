# Real-data analysis status

This file originally proposed a pluripotency-factor ChIP-nexus extension of the synthetic benchmark. That
route has been superseded by an executed CAP-SELEX × GHT-SELEX × ChIP-seq study with independent hTSC
validation.

The current plans and results are separated deliberately:

- [`capselex_feasibility.md`](capselex_feasibility.md): directed-pair feasibility and shortcut diagnosis;
- [`genomic_targeting_phase0.md`](genomic_targeting_phase0.md): frozen primary genomic design and results;
- [`trophoblast_validation.md`](trophoblast_validation.md): independent occupancy and functional tests;
- [`data_access.md`](data_access.md): exact public sources and prohibited circular assets.

The original synthetic benchmark remains a controlled positive test. It is not presented as experimental
evidence.
